# 补丁 0.4.1：补充歌曲开头 3 秒的心跳窗口

2026-10-20 · 已部署工具箱 1.25.1.0

歌曲开头 3 秒与最后 5 秒约每秒获取一次房间心跳，其他时段约每 10 秒一次，预计结束后再跟进一次。首次发现新歌已播放 2 秒时，只使用开头窗口剩余的 1 秒，不另计完整 3 秒。

## 调度与回归

- 开头窗口有独立且不可续期的截止时间，最多 3 秒。服务端快照冻结在 0 秒、在 2999/3000ms 之间抖动、同一播放实例回退进度，都不会无限续期；新播放实例重新计算。
- 首尾窗口同时计算，仍只使用一个心跳定时器。2、4、8 秒短歌的窗口重叠时不叠加请求或重复预算。
- 修正曲尾边界前唤醒过早消耗结束后跟进预算的问题：剩余 6 秒时提前唤醒不再截断后续窗口，进入最后 5 秒后仍保留预计结束后的一次跟进。曲尾每秒调度连同边界前唤醒最多约 7 秒，截止时间不可被停滞或抖动续期。
- 保留本机暂停的普通频率、失败的 10/20/30 秒退避、并发请求保护，以及退出、停用和登录失效时停止调度。成员与工具箱本机状态查询不随首尾窗口加速。
- 仍按房间快照和本机经过时间推算进度。中段手动切歌可能在普通轮询后才被发现，此时可能已过新歌开头 3 秒；不保证所有换歌都完整覆盖开头窗口或实现零延迟。

## 验证

- Node 协议、运行时、命名管道测试共 **26 项通过**，其中 17 项运行时测试。新增检查覆盖正常开头、首次发现已过 2 秒、冻结和边界抖动、短歌首尾重叠、开头失败恢复、暂停与退出。
- C# 编译成功。两项既有音频 UI 的 CS4014 警告不涉及本次修改；本次未修改页面布局，没有重复运行上一版已通过的页面布局检查。
- 主源码、工具箱源码副本与安装目录的 8 个运行组件逐一 SHA-256 相同，插件版本均为 0.4.1。
- 本轮没有真实房间验收，也没有启动或重启网易云客户端。重新打开工具箱并连接补丁后使用新调度；既有补丁会话如仍在运行，应先退出并停用再连接。
