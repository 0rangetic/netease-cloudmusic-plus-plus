# 补丁 0.3.0：网易云启动后热接入

工具箱 1.24.0.0 集成此版本。支持先普通启动网易云，再从工具箱连接；无需为了调试端口退出客户端。

通过 Python/Frida helper 接入客户端进程内 CEF DevTools API，随机命名管道和每次启动生成的认证信息连接 Node，不新增 TCP 端口。状态查询不会启动新 helper。连接失效、依赖缺失和版本不匹配均显示失败。

该版本面向网易云 3.1.41.205529 x64，严格校验 libcef.dll SHA-256、CEF wrapper、引用计数链和宿主结构。源码启动器可用 NCM_MULTI_PYTHON 指定含 frida、psutil 的 Python，或打包完整 runtime/python；仅有 Node 时需由补丁带本机调试参数启动客户端。

回归覆盖协议、运行时、命名管道、停止后重连、helper 异常恢复、页面布局和任务反馈。退出时关闭 Debugger 并删除本补丁 binding，避免旧断点残留。历史普通启动与邀请验收的匿名摘要见 [ACCEPTANCE-0.3.0.md](ACCEPTANCE-0.3.0.md)。未独立核验跨设备声学同步。

回退时同时恢复工具箱和匹配的 8 个插件运行组件。公开记录不包含实机路径、个人使用时间、进程号、歌曲或房间标识。
