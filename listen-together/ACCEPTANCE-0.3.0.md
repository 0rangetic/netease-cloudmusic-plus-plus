# 0.3.0 热接入验收摘要（匿名化）

历史测试覆盖网易云 3.1.41.205529 x64 普通启动后热接入：客户端保持运行，未打开 9222 TCP 监听，工具箱显示开始和完成反馈，补丁面板就绪。重复连接保持单 helper，三行歌词可继续运行。

官方邀请入房与当前歌曲持续跟听曾通过实机验证；成功以官方 ACK、房间匹配及持续心跳为依据。公开文档仅保留能力结论，不保存账号、邀请、令牌、房间或曲目标识、进程号、采样时间与个人播放记录。

该轮没有独立验证房主自然换歌、另一台设备的实际播放或跨设备声学同步。主界面连接反馈通过，未连接时错误文案可读性仍有改进空间。

源码自动化测试不能替代使用者在实际设备上的入房、换歌与进度核验。实现说明见 [RELEASE-0.3.0.md](RELEASE-0.3.0.md)。
