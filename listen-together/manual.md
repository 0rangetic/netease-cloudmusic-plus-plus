# 网易云多人一起听补丁

补丁 0.4.2 · 工具箱集成版 1.25.2.0 · 2026 年 10 月 22 日

让 Windows 网易云音乐加入手机端的官方多人房间，并跟随房间歌曲和进度播放。朋友继续使用官方手机 App，无需安装本补丁。现在可以先正常打开网易云，再启动工具箱里的补丁。

## 先确认能用

- 系统：64 位 Windows 10 / 11；其他电脑仍需验证。
- 网易云：**3.1.41.205529 或 3.1.42.205594 x64**。右键安装目录的 `cloudmusic.exe` → 属性 → 详细信息，可查看文件版本。热接入还会核对 `libcef.dll` 的精确 SHA-256 和运行中的结构，不匹配便停止。
- 需要已安装的官方网易云客户端和自己的登录账号。补丁不包含网易云安装程序，不共享任何人的账号。
- 工具箱集成版随带 Node 和包含 `frida`、`psutil` 的 Python 运行环境，不用另装 Node、npm、Python 或 BetterNCM。
- 独立便携包默认只附 Node.js 24.19.0 x64；若没有另外附带或指定 Python，需让补丁启动网易云。两种分发方式的操作见下文。本次 0.3.0 通过工具箱 EXE 部署，没有另发新 ZIP。

## 从工具箱使用

1. **正常打开网易云并登录。**可以使用原快捷方式，等待主界面加载完成。
2. **打开网易云工具箱，进入“多人一起听”。**点击“启动并连接”，等待任务状态显示成功，并确认网易云右上角出现“多人一起听”面板。网易云尚未启动时，也可直接使用此按钮。
3. **加入朋友的多人房间。**请朋友在官方手机 App 建房并通过私信发来多人邀请。电脑端点击邀请卡片；也可粘贴官方多人邀请链接，点击“加入邀请房间”。以面板显示加入成功、人数和同步完成为准。

无需为连接补丁重启正在运行的网易云。若账号已经在官方多人房间，补丁会尝试恢复；未登录时请先登录，再点“恢复我的房间”。关闭工具箱后，后台补丁继续运行；每次重新打开网易云后，仍需重新点击“启动并连接”。此版没有自启动或自动更新功能。

## 独立便携包如何使用

把 ZIP 完整解压到固定文件夹，保留 `app`、`runtime` 和三个 CMD 文件的相对位置，不要在压缩软件里直接运行。

默认便携包只有 Node 运行环境。请先从网易云托盘菜单完全退出客户端，再双击 `启动补丁.cmd`；补丁会以本机调试参数启动网易云。找不到安装目录时，请选择 `cloudmusic.exe`。普通用户权限即可。不要只关闭主窗口，因为它可能只是缩到托盘。补丁不会强制关掉正在播放的客户端。

若要让独立包也能在网易云已普通启动后连接，需要包含 `frida`、`psutil` 的 Python：可由维护者使用 `build-portable.ps1 -PythonDirectory <完整运行环境目录>` 打包到 `runtime/python`，或在启动前将环境变量 `NCM_MULTI_PYTHON` 设置为该环境中 **python.exe 的绝对路径**。只放一个 `python.exe` 或只安装不含依赖的 Python 都不足以热接入。没有该环境时，请按上一段先退出客户端，再由 Node 便携包启动。

启动后的命令窗口可以关闭，后台进程会继续工作。默认 Node 包每次重新打开网易云都从 `启动补丁.cmd` 进入；附带或指定了完整 Python 环境的包，可以先打开网易云再运行此入口。

## 面板按钮怎么用

| 按钮 | 作用 |
| --- | --- |
| 读取私信邀请 | 从当前打开的私信对话提取官方多人邀请；不会发送消息。识别后再点加入。 |
| 加入邀请房间 | 加入已读取或输入框中粘贴的官方多人邀请。多个房间时请粘贴目标链接。 |
| 恢复我的房间 | 从服务器查询并恢复当前账号已加入的多人房间。 |
| 重新同步 | 恢复跟听，并把歌曲和播放进度对齐房间。 |
| 本机暂停 | 只暂停你的电脑；其他人继续听，你的账号仍保持房间在线。 |
| 退出房间 | 正式退出官方多人房间，暂停本机；补丁面板保留。 |
| 退出并停用补丁 | 成功退出房间后停止同步、移除面板并关闭后台桥。退出失败时保留错误，不冒充成功。 |
| 收起 / 展开 | 只收起或展开面板，不退出房间。 |
| 任务消息记录 | 展开查看开始、完成、失败或部分失败的记录。 |

工具箱的状态查询、退出并停用，以及便携目录里的 `查看状态.cmd`、`退出并停用.cmd` 均兼容本机热接入与原有调试连接。状态查询不会启动新补丁；连接已断开时会说明情况，不强制结束客户端或其他 Node 进程。

## 已有功能与限制

已实现官方多人邀请解析、加入、恢复、人数显示、自动跟随歌曲、进度对齐、本机暂停和退出。采用官方服务端的真实账号与房间，正常情况下其他成员应能看到你；朋友手机上的实际头像刷新仍需双方核对。

此版只做入房和同步跟听。**尚不支持在电脑补丁里开房、推歌、编辑共同队列、房间聊天或把原生“下一首”映射为多人切歌。**请在手机端完成这些操作；电脑会跟随服务端的结果。

同步平时约每 10 秒读取一次房间心跳，歌曲开头 3 秒和最后 5 秒约每秒读取一次，并在预计结束后跟进一次，帮助自然接歌。开头窗口只用实际剩余时间，最多 3 秒；曲尾连同边界唤醒最多约 7 秒。进度卡住时自动降回普通频率，短歌的首尾窗口不重复计时或发送请求；请求失败按 10、20、30 秒退避。本机暂停不进入高频模式。其他成员提前切歌仍可能延迟一个普通轮询周期，首次发现时也可能已过开头窗口，不能保证每台电脑严格零延迟。暂停请用补丁面板的“本机暂停”；网易云原生暂停、下一首或拖进度可能在下一轮同步时被房间状态覆盖。保留网易云正常歌曲权限和会员限制，不解锁无法收听的歌曲。

热接入与发布检查见 `RELEASE-0.3.0.md`。其他电脑、长期挂机、不同权限组合、断网恢复与多种插件并用尚未完成全面验收。客户端或网页资源更新后，即使 EXE 版本相同，也可能因模块变化停止工作。

## 常见问题

**提示缺少 Python / frida / psutil**

工具箱集成版请检查随带的 `runtime/python` 是否完整。独立便携包默认没有这套环境：可补齐完整环境或设置 `NCM_MULTI_PYTHON`，也可从托盘完全退出网易云，再由 `启动补丁.cmd` 启动。补丁不会把依赖缺失显示为连接成功。

**提示 NCM_MULTI_PYTHON 不可用**

该变量必须指向可运行且包含 `frida`、`psutil` 的 `python.exe` 绝对路径，不能填文件夹或相对路径。修正变量后重新启动补丁。

**提示版本不支持 / CEF 版本不匹配 / 模块结构不匹配**

核对 `cloudmusic.exe` 的文件版本与 x64 架构。相同 EXE 版本仍可能有不同 DLL 或网页资源；请反馈错误文字，等待适配，不要跳过哈希校验或手改模块编号、偏移强行运行。

**提示无法读取主进程 / 安装目录不一致 / 多个主进程**

使用同一 Windows 用户和权限运行网易云与工具箱，核对选择的 `cloudmusic.exe` 与正在运行的客户端属于同一安装目录。多个网易云主进程会使目标不明确，请正常退出多余实例后重试。

**没有面板，或点击仍提示暂不支持**

先在工具箱刷新状态，或运行 `查看状态.cmd`。如果桥已断开，重新启动补丁；若遗留面板或旧版本补丁阻止启动，先在原面板退出房间，再完全退出网易云并重开。也可以先打开有邀请的私信对话，使用“读取私信邀请”或直接粘贴官方多人链接。

**邀请识别失败**

仅支持官方多人入口，双人邀请和“跟听”链接不适用。请朋友重新发送多人邀请；当前对话包含多个不同房间时，粘贴明确的目标链接。补丁不会根据一段“我们一起听歌吧”的说明文字猜房间。

**token 校验失败 / 加入失败**

查看面板任务消息，确认网络可访问网易云及其易盾服务。官方拒绝或风控不会被显示为成功；请求超时后先用“恢复我的房间”核对是否已经入房，再决定重试。

**有声音但不同步 / 换歌后没跟上**

点击“重新同步”，检查是否处于“本机暂停”或“同步中断”。若提示歌曲权限或加载错误，先确认同一账号在官方客户端能完整收听该歌。

**端口 9222 被占用**

这是由补丁启动客户端时的调试端口问题。关闭占用该端口的调试程序后重试；有完整 Python 环境时，也可先正常启动网易云，再热接入。补丁只接受网易云主页面，不连接其他浏览器页面。

**换账号、重载网页后怎么恢复**

换账号后旧同步会停止。登录新账号后点击“恢复我的房间”。网页重载后请重新启动补丁；若旧面板或连接无法清理，正常退出网易云后重开。此版不自动重新注入网页。

## 退出、删除与数据

用“退出并停用补丁”或对应停止入口停用。确认退出成功后，可继续普通使用网易云；需要清除整次客户端会话时，再正常退出并重开。补丁没有覆盖客户端 EXE、DLL 或网页包，无需还原客户端文件。原有 9222 调试端口随客户端进程退出而关闭。

工具箱状态与日志保存在 `%LOCALAPPDATA%\NeteaseToolbox\MultiListen\`。热接入的状态、helper 日志与临时目录位于其 `native\` 子目录；其中 `state.json` 含本机管道认证信息，不要分享。独立启动器的客户端路径与普通桥日志保存在 `%LOCALAPPDATA%\Netease\CloudMusic\CodexMulti\`。这些本机目录不会随包分发；彻底删除时，在停用补丁后删除相应状态目录和解压文件夹。

包内不附带 Cookie、登录信息、私信或原作者的本机日志。官方入房令牌仅在内存中使用；程序仍会按正常入房操作向网易云官方服务器发送当前账号的房间请求。

本机热接入通过随机命名管道和每次启动生成的认证信息通信，不新增 TCP 端口。由补丁启动客户端时使用本机 `127.0.0.1:9222` 调试通道；不要把它通过路由器、反向代理或公网隧道开放给别人。
