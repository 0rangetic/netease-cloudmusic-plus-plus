# 补丁 0.4.2：适配网易云 3.1.42.205594（页面模块 id 变更）

2026-10-21/22 · 已部署工具箱 1.25.2.0

修复网易云 3.1.42 升级后无法接入的问题。

## 根因

网易云 3.1.42.205594 的渲染模块布局与 3.1.41.205529 不同。

故障有两层，**只改版本号不够**：

1. **版本门写死**：`native_bridge.py`、`start.ps1`、`MultiListen.cs` 都只认 `3.1.41.205529`，升级后直接拒绝接入。
2. **渲染层 webpack 模块 id 发生位移**（真实原因）：`runtime.js` 依赖的是硬编码 id，3.1.42 上已失效：

   | 能力 | 3.1.41.205529 | 3.1.42.205594 |
   | --- | --- | --- |
   | 多人邀请解析器 | `r(2093).c` | **`r(2092).c`** |
   | 播放进度 observable | `r(109).b.getValue()` | **`r(110).b.getValue()`** |
   | 旧的 `r(2093)` | 解析器 | 变成一个 React 相关模块（调用即抛 React #321） |
   | 旧的 `r(109)` | 含 `b.getValue` | 变成一组 API 函数，`b` 不再有 `getValue` |

   因此升级后补丁会在第 9 行的结构门抛“客户端模块结构不匹配，停止安装”；即使放宽版本门也无法工作。

## 改动

- **按能力解析模块，不再硬编码 id**：`runtime.js` 新增 `resolveClientModules()`，按形状定位两项能力并在使用前校验：
  - 解析器：遍历模块导出，用双层 `orpheus://open?url1=…` 样例实测调用，取返回 `{action:'multiListenTogether'}` 的那个；`control.mjs` 的点击钩子改为通过 `window.__ncmMulti.parserTarget()` 绑定，不再写死 `__wxr(2093).c`。
  - 进度：取源码含 `position`/`progress` 且导出数值 `getValue()` 的模块。已实测 `r(110).b` 为真实播放进度（毫秒），排除 `r(117).e/f`（恒 0）与 `r(181).c`（恒 1）。
  - 任一能力找不到即返回 `null` → 抛“客户端模块结构不匹配”，**明确失败而不是跑错模块**。
- **版本门改为白名单**：`native_bridge.py` 的 `SUPPORTED_VERSIONS`、`start.ps1` 的 `$supportedVersions`、`MultiListen.cs` 的 `MultiListenClientVersions`，精确匹配 `3.1.41.205529` 与 `3.1.42.205594`（非前缀/区间）。`CEF_SHA256` 校验保持强制，`native-agent.js` 未改动。
- 补丁版本 0.4.1 → **0.4.2**，工具箱 1.25.1.0 → **1.25.2.0**；文档与便携说明同步。

## 验证（含真实客户端）

- Node 测试 **19 项运行时测试 + 4 项协议 = 23 项全部通过**（`node --test protocol.test.mjs runtime.test.mjs`）。新增两项：同一补丁在 3.1.41 与 3.1.42 两种布局下都能正确解析（断言 `moduleMap.parser` 分别为 `2093.c` / `2092.c`）；解析器失效时拒绝安装。
- `native-transport.test.mjs` 在本环境无法运行：它需要 `spawn` 子进程并 `mkdtemp` 到工作区外，被当前沙箱以 EPERM 拒绝。该文件本次未改动。
- 历史实机检查覆盖热接入、模块解析、恢复官方房间、当前歌曲进度跟随以及干净退出。公开文档不保存任何账号、邀请、房间、歌曲或进程标识和个人播放采样。
- C# 编译成功（仅两项既有音频 UI 的 CS4014 警告）。`validate-multi-listen-layout.ps1` 通过，页面标题显示 **v1.25.2.0**。
- 源码、仓库 `toolbox/multi-listen/`、正式目录 `multi-listen/` 的 8 个组件逐一 SHA-256 相同。

## 仍需用户确认

本轮验证覆盖了“热接入 + 模块解析 + 恢复房间 + 跟随进度”，但**没有用真实鼠标点击私信邀请卡片**，也没有做跨设备声学同步核验。请按实际使用确认：

1. 正常打开网易云 3.1.42 → 工具箱 1.25.2.0 →“多人一起听”→“启动并连接”，确认任务栏“完成”且网易云右上出现面板。
2. 让朋友发一条真实的多人邀请私信，**点击邀请卡片**验证点击入口（面板需显示“邀请点击入口已连接”）；失败时可用面板“读取私信邀请”或粘贴链接。
3. 按用户习惯逐帧核对换歌与进度对齐，而不只看“补丁已连接”。

若将来客户端再次更新：先看面板/日志是否报“客户端模块结构不匹配”。若报，说明模块 id 又变了，按 `resolveClientModules` 的判据重新核对，并在 `SUPPORTED_VERSIONS` 补上新版本、先核对 `libcef.dll` 哈希是否变化。
