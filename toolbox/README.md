# 网易云工具箱

当前公开源码版本：**2.6.0.0**。便携包的实际版本以下载标签为准。

## 手机网易云重播同步（2.2.0）

“听歌画像 → 本机播放统计”顶部新增“手机同步”。电脑端显示 6 位配对码，手机端 Music Plus 的“电脑同步”输入配对码后完成绑定；手机和电脑必须连接同一局域网，并登录同一个网易云账号。配对时电脑和手机都会校验账号，不一致会拒绝。

配对成功后首次补传手机本地保留的全部网易云重播，之后只传增量。手机在局域网内自动发现电脑；成功一次后 1 天内不再自动上传，期间新重播先排队；失败或未发现电脑时 1 小时后重试。手机端保留“立即同步”按钮用于手动补传。电脑端只有在已配对手机时才随工具箱启动接收端；没有配对记录时不会监听，首次打开“手机同步”窗口才临时启动。首次监听时 Windows 可能询问防火墙权限，需要允许专用网络访问。

手机只记录 `com.netease.cloudmusic` 的单曲循环和回拖重播；其他媒体仍可由手环控制，但不进入重播历史。升级前已有的其他媒体记录保留在 `phone-play-history.jsonl` 中，只是不再显示、导出或上传。电脑端把手机重播段按“重播次数 + 1（推算首遍）”并入“连续重播记录”和歌曲累计次数；电脑与手机不会同时播放，因此不做跨设备去重。网络失败重传时按事件 ID 幂等，避免同一条手机记录被重复计数。

手机 JSONL 存档位于 `%LOCALAPPDATA%\NeteaseToolbox\LocalPlayback\<uid>\phone-repeats.jsonl`，接收日志为同目录上一级的 `phone-sync.log`。验证：`test_local_playback.mjs` 覆盖网易云来源过滤、手机独有账号、同请求重复事件和“重播 +1”合并；`PhoneSyncValidation.cs` 覆盖局域网发现、配对码、账号绑定、令牌、网易云归档和幂等重传。

## 音乐记忆移除 LifeRecall（1.29.0）

“音乐记忆考古”不再读取或展示 LifeRecall 时间线、位置、运动和照片数据，删除了时间线目录选择及相关上下文展示；检索只使用本机播放记录和本地 `.lrc` 歌词，结果保留播放时间、歌曲信息和歌词命中依据。`memory_recall.py` 同步移除了 LifeRecall 事件适配器与结果字段。

验证：`test_portable.py` 覆盖自定义输出目录歌词匹配及冲突歌词排除；本机检索脚本通过 Python 单元测试。

## 按情绪/曲风生成红心歌单（1.28.0）

“曲风分析”页新增“筛选生成歌单”。读取当前账号的红心歌单和本地曲风/情绪标签后，可同时勾选多个情绪与曲风。标签列表支持三种状态：左键勾选，右键标记 × 表示硬性排除——只要歌曲包含任一 × 标签，就不会进入歌单，类似黑名单；再次右键可取消排除。默认最低命中数为勾选标签数的一半，单数向上取整（例如 4 个标签默认至少命中 2 个，3 个标签默认至少命中 2 个）；可取消“按半数自动”后手动调整。未分析过的歌曲不会加入。

对话框用柱状图显示至少命中 1、2、… 个已勾选标签时分别有多少首歌，并高亮当前最低命中数；硬排除的歌曲不计入图表和匹配数量。图表、红心总数、有标签数量、未分析数量、硬排除标签数和当前匹配数量会随勾选、排除和阈值实时更新。歌单名称默认由勾选的前三个标签生成，可手动修改；默认创建私密歌单，也可取消私密。确认后通过网易云歌单接口创建，并按每 200 首分批加入。创建成功、取消、失败和“歌单已创建但部分歌曲加入失败”都会显示在主界面任务状态与任务消息中；部分失败会保留已创建歌单的 ID 和已加入数量。

验证：`validate-tag-playlist.ps1` 覆盖标签计数、累计匹配分布、半数阈值（含单数向上取整）、手动阈值、右键硬排除、排除与勾选冲突时排除优先、图表排除后计数、默认命名、按钮布局和最小窗口布局。测试使用合成样本；线上创建与分批加入需使用者自行确认，测试记录不包含真实账号统计。

## 规则化智能歌单：预览、手动调整与预设（2.1.0）

标签筛选对话框新增“预览匹配歌曲”。预览窗口与筛选框同时存在，修改标签、硬排除或最低命中数时实时刷新；列表显示歌曲、歌手、曲风、情绪、命中的筛选标签、命中数、加入状态，并支持按歌名/歌手搜索、按命中数或歌名排序、按规则状态筛选。选中歌曲后，下方显示具体匹配依据，包括命中标签、命中数、最低命中数和被硬排除的标签。只有符合规则的歌曲可以取消或恢复加入，批量按钮可一次恢复或取消当前符合条件的歌曲。

预览中的手动取消只影响本次创建，不修改歌曲标签，也不会写入规则预设。手动取消按歌曲 ID 在本次筛选会话中保留：暂时不符合规则的歌曲不计入“手动排除”，重新符合后仍保持取消状态；载入规则预设会重置手动调整。主对话框实时显示“符合规则 / 手动排除 / 最终创建”三个数量，全部取消时创建按钮禁用，避免空歌单。

“规则预设”可保存当前标签、硬排除、最低命中模式和数值、默认歌单名，支持载入、保存、重命名、删除和覆盖同名预设。预设保存在 `%LOCALAPPDATA%\NeteaseToolbox\PlaylistRules\<uid>\presets.json`，按网易云账号隔离；文件带格式版本，使用临时文件加 `File.Replace` 原子替换，程序中断不会覆盖已有预设。预设不保存歌曲 ID、手动取消记录、Cookie、登录凭证、AI Key 或听歌记录；当前标签列表中不存在的预设标签会在载入时忽略并提示。

创建前会再次显示歌单名称、可见性、筛选标签、硬排除、最低命中、符合规则数量、手动排除数量和最终加入数量；确认后才调用原有创建接口，并按每 200 首分批加入。若歌单已创建但部分歌曲加入失败，任务消息会报告歌单 ID、成功数量和失败数量，不会自动重新创建同名歌单。

验证：`validate-tag-playlist.ps1` 在原有过滤与布局测试之外，新增逐曲评估/匹配依据/手动状态测试、预设存储测试（保存、加载、重命名、删除、账号隔离、损坏文件、敏感字段排除）和编辑器界面测试（非模态预览联动、搜索/排序/状态筛选、手动取消与恢复、批量操作、预设保存与载入、最小窗口布局、创建确认及最终提交歌曲）。测试使用合成歌曲和临时账号目录，不创建真实歌单，也不读取或修改真实红心歌单。

## 多人一起听（1.25.2）

“多人一起听”页把独立的多人一起听补丁（源码位于仓库 `listen-together/`，运行文件为工具箱目录下的 `multi-listen/`，两处逐字节一致）接进工具箱。可以先正常打开网易云，再点“启动并连接”，无需退出或重新启动客户端；未运行时工具箱会自动启动网易云。工具箱核对实际主进程的安装路径、版本与 x64 属性；已有本机 9222 调试通道时继续复用，否则通过随包 Python、Frida 建立进程内通道，底层再次核对客户端和 CEF 文件的 SHA-256。首次建立通道约需 30 秒，主界面会显示连接进度和失败原因。

“退出并停用”会让电脑退出房间、卸载补丁并结束后台桥进程。关闭工具箱不会关闭已连接的多人房间；页面状态每 5 秒刷新，后台桥日志位于 `%LOCALAPPDATA%\NeteaseToolbox\MultiListen\bridge.log`。运行环境检查同时核对 `native-client.mjs`、`native-host.mjs`、`native_bridge.py` 和 `native-agent.js`，部署时需随 `multi-listen/` 一起携带。

0.4.2 插件平时约每 10 秒获取房间心跳，歌曲开头 3 秒与最后 5 秒约每秒一次，预计结束后再跟进一次；开头窗口最多 3 秒，曲尾含边界唤醒最多约 7 秒，首尾窗口重叠时不叠加请求，失败按 10、20、30 秒退避。工具箱每 5 秒读取的本机状态不额外发送房间心跳。0.4.2 仅为客户端 3.1.42 升级放宽版本门，调度与 0.4.1 相同。具体调度、验证及发布记录见 `listen-together/RELEASE-0.4.2.md`。

补丁面向手机端创建的官方多人房间：支持恢复已加入的房间、跟随换歌与进度、本机暂停和退出；不支持建房、推歌、共同队列与聊天。朋友通过私信发来多人邀请后，点击邀请卡片，或在网易云右上角补丁面板粘贴邀请链接即可加入。适配网易云 3.1.41 x64 Build 205529 与 3.1.42 x64 Build 205594（两版 libcef.dll 相同）；其他版本变化需要重新适配，不能沿用进程内函数地址。

验证：在 `listen-together/` 运行 `node --test protocol.test.mjs runtime.test.mjs native-transport.test.mjs`，0.4.1 起的 26 项测试覆盖首尾窗口、停滞、抖动、短歌重叠、失败退避与生命周期；0.4.0 发布时的隔离页面检查通过，本次未修改页面布局。本轮未连接真实房间，调度及发布记录见 `listen-together/RELEASE-0.4.1.md`。0.3.0 的历史进程内接入、真实邀请入房、当前歌曲跟随、停用重连及 helper 异常恢复记录见 `listen-together/RELEASE-0.3.0.md`；跨设备声学同步尚未独立验收。

## 每日签到（1.22.0）

左侧“每日签到”分别执行当前账号的云贝签到和黑胶乐签，默认每天北京时间 08:30 自动运行。可修改时间并“保存设置”，或点击“立即签到”。保存时更新当前 Windows 用户的 `NeteaseToolboxDailySignin` 计划任务，直接调用本工具箱 `--daily-signin --scheduled`，不保存密码；工具箱已有的本机加密登录凭证只在内存中使用。

Windows 用户已登录且电脑联网时，退出工具箱后仍可由计划任务执行。错过时间会在登录 Windows 或打开工具箱后补签；未登录 Windows 时不会执行，也不会主动唤醒关机的电脑。工具箱运行期间每分钟检查一次，失败后间隔 30 分钟重试失败项；计划任务失败后最多重启三次。取消勾选并保存可关闭自动执行，手动签到仍可用。

签到请求优先直连网易云，直连失败时才尝试系统代理；系统代理未运行不会阻断签到。云贝签到使用 `/api/pointmall/user/sign`，`sign=true` 表示本次成功，`false` 表示今日已签到；必须有明确的布尔字段，不能只看 `code=200`。字段语义参考 [chaunsin 的接口定义](https://github.com/chaunsin/netease-cloud-music/blob/master/api/weapi/yunbei.go)。黑胶乐签执行 VIP 签到和 EAPI 乐签详情调用，并查询当日非零记录 ID 与有效签到时间确认。不会执行刷歌、关注作者、发布动态或其他任务。

成功缓存和最近 200 条任务消息按账号保存在 `%LOCALAPPDATA%\NeteaseToolbox\DailySignin\<uid>\`；全局时间及开关位于 `daily-signin-settings.json`。页面展示持久记录，后台执行的失败也会在主界面任务消息中显示。一项失败时显示“部分失败”，成功项不重复执行；切换账号后使用该账号的独立记录。

验证：`validate-daily-signin.ps1` 离线覆盖加密独立样本、真假成功、部分失败重试、跨天、账号隔离与持久消息；加 `-Live` 验证本机当前账号及 EAPI 传输。`validate-daily-signin-layout.ps1` 在禁用启动任务的隔离窗口检查最小尺寸、主题、导航及反馈。

Windows EXE 前端，集中管理 NCM 转换、播放记录、音乐记忆检索、曲风分析、听歌画像、多人一起听、网易云三行桌面歌词和网易云音频转麦克风。

“设置与维护 → 界面主题”可选择深色模式或浅色模式，立即应用到主界面、歌曲列表、音乐记忆、日志、任务消息及设置弹窗。首次使用默认深色；偏好保存在 `%LOCALAPPDATA%\NeteaseToolbox\appearance.txt`，下次启动自动恢复。浏览器图表报告使用独立的报告样式。

主题下方还可选择按钮颜色、背景图片和 UI 字体。主要按钮、普通按钮与当前导航使用自选颜色，文字自动选择黑色或白色以保持对比度，删除操作保留警示红色。背景支持 JPG、PNG、BMP，会复制到本机外观目录，原图片移动或删除不影响下次启动；模糊滑块支持 0–30，鼠标松开或键盘调整后应用并保存。背景铺满窗口并加上主题遮罩，列表和卡片保留清晰底色。字体选择使用已安装的字体并保留标题与正文的字号层级。“恢复默认外观”恢复颜色、图片与字体，保留深浅主题。配置与处理后的背景位于 `%LOCALAPPDATA%\NeteaseToolbox`，不会同步到 GitHub。

## 使用

自定义背景启用时，左侧导航、歌曲表格及表头透出同一张背景；选中行保留高亮。背景按窗口尺寸缓存，切页只复用缓存，页面切换期间合并重绘以减少卡顿和闪烁。移除背景后恢复主题的实色表格与导航。

自定义背景也会透过设置卡片、音乐记忆检索框、时间线目录、证据详情及画像文本区。文本控件保留原生输入法、选择和复制；关闭背景后恢复当前主题底色。按钮、下拉框和日期选择器保留便于辨识操作的底色。

1.14.10 将“曲风分析”表格改为独立绘制控件，配合独立的纵向与横向滚动条：滚动只改变行位置，不再经过原生 ListView 的旧像素搬移。滚轮输入按约 16 毫秒合并，绘制最新位置；背景、文字行和完整画面分别缓存，文字行缓存上限随可见行数变化。保留单行选择、右键手动修正、双击打开歌曲、键盘导航和表头列宽调整。其他页面的表格暂时沿用原实现。

1.14.9 是此前的 GitHub 源码回退点，其快速滚动仍有背景与歌曲行重复的问题。1.14.10 修复该问题。新控件的离屏测试涵盖连续滚轮消息、定时刷新请求、固定背景、数据更新、点击映射及缓存释放；离屏测试不能代替不同机器上实际滚动的逐帧观察。

背景图片的“图片适应模式”参照 Windows 桌面设置，支持填充、适应、拉伸、平铺、居中。填充等比例铺满并裁剪超出部分；适应等比例完整显示并使用主题底色留边；拉伸铺满整个窗口；平铺按图片原始尺寸重复；居中按原始尺寸居中，超出窗口的部分裁剪。切换立即生效并自动保存，旧配置默认填充；模糊与主题遮罩在所有模式下继续生效。新选图片保存原始尺寸；旧版本已保存的图片以现存副本尺寸为准，可重新选择原图更新。

打开程序目录中的 `网易云工具箱.exe`。界面使用左侧功能导航，将音乐转换、曲风分析、听歌画像和设置维护分开显示；当前页面只保留与该功能有关的操作。程序启动时会自动连接三行歌词补丁；顶栏按钮可随时关闭或重新开启。关闭工具箱窗口不会关闭已运行的三行歌词补丁。

程序监控用户在“选择音乐目录”中指定的文件夹及其子目录中的 `.ncm` 文件。“音乐转换”页分为“待转换歌曲”和“已转换歌曲”两个标签页；点击“转换全部新歌”处理全部待转换歌曲，也可以在列表中多选歌曲后只转换选中项。在“已转换歌曲”中多选歌曲后，点击“重新转换选中”可可靠覆盖更新已有的音频、标签、歌词和封面。任一标签页中只选中一首歌曲，再点击“提取选中封面”，选择保存文件夹后即可单独导出封面，不会重新转换音频。点击“打开最新输出”会在资源管理器中定位最近一首歌曲的转换文件。

双击待转换、已转换、曲风分析、画像歌曲明细或音乐记忆结果中的歌曲，会按歌曲 ID 打开网易云客户端播放页面；未安装客户端或客户端启动失败时打开网易云网页。读取本地歌曲 ID 时只读取 NCM 元数据，无法确定歌曲时会在任务消息中显示原因。

点击“运行日志”可打开独立的日志窗口。关闭窗口后，本次运行的记录仍会保留；再次点击按钮即可继续查看。

主界面底部的任务状态栏会显示转换、重新转换、去重、曲风刷新、画像分析等操作的开始、完成、失败或部分失败结果。点击“任务消息”可查看本次运行最近的任务反馈及错误，详细过程仍保留在“运行日志”中。

“曲风分析”页读取网易云歌曲百科的曲风与情绪标签，显示主曲风、其他曲风、情绪、来源和状态；“导出 CSV”可保存分析结果。标签缓存在 `%LOCALAPPDATA%\NeteaseToolbox\GenreAnalysis\analysis.sqlite3`，未收录歌曲会明确标出，可右键歌曲选择“手动修正曲风”。标签可能有多个，并非带有可信度分数的模型预测。

“听歌画像”页分为“所有画像”“近30天画像”和“歌曲明细”。近30天是最近30天内新增红心的歌曲，而非最近30天播放过的歌曲；其中的曲风对比使用同一批歌曲百科标签，按有曲风标签的歌曲为分母。一首歌可有多个曲风，各项占比可能合计超过 100%。两份画像各有刷新按钮，点击时会重新读取网易云档案、重算并打开对应页的完整图表报告；启动时只读取现有本地缓存。网易云档案保存在 `%LOCALAPPDATA%\NeteaseToolbox\Profile\netease-profile.json`。报告输出目录由工具箱旁的 `chart-report-project.txt` 指定，默认是账号目录下的 `Reports`；报告由 `portable_report.py` 本机生成，不依赖 Codex 或 Node.js。

“音乐记忆考古”页按自然日期/时段、歌名、艺人、专辑和本地 `.lrc` 歌词检索播放记录，结果显示播放时间、歌曲信息和命中依据；不读取位置、运动、照片或外部时间线目录。歌曲歌词从当前音乐输入目录及自定义转换输出目录中匹配到的 `.lrc` 文件读取，无法唯一匹配时不拿歌词作为证据。

音乐记忆结果受本机播放记录覆盖范围限制。网易云最近播放接口不支持翻页，工具箱每 5 小时同步一次；两次同步间若新增记录超过接口窗口，较早记录无法补回。因此“没有找到”不能证明当时没有听过。

检索和排序默认完全在本机运行，不保存查询或派生索引。勾选“AI 排序”才会调用“AI 画像接口与提示词”中配置的服务；请求只包含本次检索描述、最多 20 条候选的歌名/艺人和短歌词片段。不会发送播放记录、歌词文件或设备信息，也不会保存模型请求和响应。模型只调整本机已找到的候选顺序，本机时间与歌词证据仍显示在结果中；未配置接口、AI 总开关关闭或请求失败时，本机结果保留，任务消息会报告部分失败。

默认输出位于每首歌曲所在目录的 `unlock` 子目录。“设置与维护”页可选择输出目录；新转换的文件会写入选定目录，并保留输入目录下的歌手子目录。设置保存在工具箱旁的 `output-folder.txt`，旧的一键转换批处理也会读取它。点击“恢复默认”可撤销设置。已有输出文件不会移动。音频标签、歌词标签和 `.lrc` 文件仍由 `convert.ps1` 生成（取决于可用的歌词和 Cookie）。

转换新歌时会自动将封面嵌入音频，并以与音频同名的 `.cover.jpg` 或 `.cover.png` 保存在输出目录。封面优先取自 NCM 内嵌图片，缺失或损坏时再尝试元数据中的 `albumPic` 地址；嵌入音频需要 FFmpeg。两处都没有可用图片时，“运行记录”会显示“封面下载失败”，歌曲转换仍会继续。

添加歌曲时会自动去重，也可以在“设置与维护”页点击“扫描并去重”，立即检查整个歌曲目录。程序优先使用网易云歌曲 ID 判断是否为同一曲目，缺少 ID 时使用标准化后的曲名和艺人；同曲按码率、无损格式、文件大小依次选择质量更高的一份。较低音质的 NCM 源文件及其已经生成的音频、歌词和封面会被直接删除，不创建备份；现场版、翻唱版等曲名不同的版本不会合并。

## 网易云扫码登录（1.15.0）

点击左侧“登录网易云”，默认打开内置的网易云官方网页。在右上角点击“登录”，用手机网易云音乐扫一扫并确认；若网易云要求滑块或行为验证，在官方网页内自行完成。工具箱自动接收登录凭证，无须打开开发者工具或手动复制 Cookie。官方浏览器窗口使用 InPrivate 临时会话，不启用密码保存。备用接口二维码遭遇 8821 时会指引使用官方网页，不自动反复重试。窗口显示等待扫码、待手机确认、成功或过期；刷新按钮可生成新二维码。下次启动自动读取登录状态，失效时重新扫码。备用入口可导入 Cookie，退出账号会删除本机登录凭证。

凭证使用当前 Windows 用户的 DPAPI 加密，保存在 `%LOCALAPPDATA%\NeteaseToolbox\Auth\session.dat`，不会上传到第三方服务。扫码接口直接请求网易云，二维码由本地随附的 qrcode 8.2 源码生成。该源码的许可证在 `vendor/qrcode-LICENSE`。网易云接口属于非官方接口，后续变动可能需要更新适配。

账号信息、红心歌单从当前登录状态读取；画像缓存、AI 结果和播放记录按账号 ID 分目录保存。只有旧档案的账号 ID 与新登录账号一致时，才复制旧画像和播放缓存到新目录，原文件保留。分析进行中不能切换或退出账号。转换歌词、曲风、画像与播放同步统一使用工具箱凭证，不再依赖 MusicLyricApp。

## 播放记录自动同步

工具箱会使用自己保存的网易云登录凭证，每 5 小时读取一次网易云账号最近播放记录，并将歌曲、歌手、专辑、设备信息和网易云提供的精确播放时间追加到 `%LOCALAPPDATA%\NeteaseToolbox\Playback\账号ID\play-history.csv`。记录时间保留服务器返回的 Unix 毫秒，同时提供 UTC 和本地时区时间。手机、电脑和其他已登录设备的播放都会出现在同一份账号历史中。

网易云接口不支持翻页；最近播放接口返回窗口有限。工具箱启动时立即同步一次，之后每 5 小时同步并按歌曲 ID 和播放时间去重。若两次同步之间新增播放超过接口返回窗口，超出窗口的记录无法补回。没有服务器播放时间的项目会跳过，不会伪造时间。

同步优先直连网易云；发生连接失败或超时时尝试系统代理。首次或后续同步失败均会在主界面及任务消息中显示原因，网络错误每分钟自动重试；登录或数据状态错误每 5 小时重试，重新扫码后立即同步。

首次打开工具箱后会注册当前 Windows 用户的登录启动项。之后每次登录时工具箱会在后台启动并同步账号记录；关闭主窗口只会隐藏到系统托盘。托盘菜单可打开工具箱或记录文件夹、退出本次运行，或关闭自动同步并移除登录启动项。需要保持工具箱中的网易云登录有效。
关闭到托盘和再次打开时保留窗口及表格句柄，避免重建全部控件与壁纸缓存导致卡顿。托盘中的退出仍会释放窗口和后台资源。
表格使用完整可见画面缓存：背景、全部可见行文字及选择效果先画到同一张位图，再一次性显示；未变化的画面复用缓存，只有可见区域参与绘制。曲风分析由独立控件管理行位置、选择和绘制；其余表格继续使用原生 ListView 管理数据、滚动位置和交互，缓存复用前核对首行、行位置和表头偏移，并将局部刷新扩展到整个表格。窗口尺寸变化的背景生成请求合并到布局结束后。
## 构建

运行 `build.ps1`，使用 Windows 自带的 .NET Framework C# 编译器生成 EXE。官方网页登录依赖 Microsoft WebView2：构建缺少 SDK 时运行 `prepare-webview2.ps1`，从微软 NuGet 下载固定版本 1.0.4258.31 并验证 SHA-256。音频转麦克风依赖 NAudio 2.2.1：缺少时运行 `prepare-naudio.ps1` 下载并校验 SHA-256。部署时同时携带 `Microsoft.Web.WebView2.Core.dll`、`Microsoft.Web.WebView2.WinForms.dll`、`WebView2Loader.dll`、`NAudio.Core.dll`、`NAudio.Wasapi.dll` 和 `NAudio-LICENSE.txt`；使用电脑需安装 Evergreen WebView2 Runtime。SDK DLL 和编译产物不提交到 GitHub。部署时将 `网易云工具箱.exe`、`netease_auth.py`、`vendor` 目录、`genre_analysis.py`、`profile_fetch.py`、`profile_first_listen.js`、`profile_analysis.py`、`portrait_ai.py`、`memory_recall.py`、`chart-report-project.txt` 和工作区根目录的 `convert.ps1` 放在同一目录。三行歌词运行文件位于程序目录的 `Lyric3/`。多人一起听还要求工具箱目录下的 `multi-listen` 子目录；源码在仓库 `listen-together/`，修改后必须同时更新两处。

AI 画像仅在手动刷新对应画像时调用用户配置的 OpenAI 兼容接口，解读显示在浏览器图表报告，不改变 EXE 内规则统计。请在“设置与维护 → AI 画像接口与提示词”配置接口、模型和密钥。密钥使用当前 Windows 用户的 DPAPI 加密，保存在 `%LOCALAPPDATA%\NeteaseToolbox\Profile\portrait-ai.json`；报告只保存生成的解读和状态，不包含密钥。近30天解读的请求会附带近期与全量的曲风、情绪、累计播放艺人聚合及占比差值，便于模型直接对比；还会附带最近30天本地连续重播（按连续段开始时间筛选，含重复遍数、单段最长重复、手机/电脑拆分及 Top 歌曲/连续段）。全量解读仍发送逐曲明细，不发送重复数据。
同一设置页的“启用 AI 分析”总开关同时控制所有歌曲与近30天画像。关闭后两种画像仍更新规则统计及图表，但不会向 AI 接口发送请求；报告会明确显示已停用。保存开关时会同步重建两份本地图表报告，不会调用 AI。
“听歌画像”页顶部的“刷新全部画像”会先读取一次网易云档案，再计算所有歌曲与近30天两类规则画像；AI 开启时依次生成两份 AI 解读，最后只构建一次报告并同时导出两份 HTML。任一 AI 解读失败时任务状态为“部分失败”，图表仍会更新，并显示安全的接口错误码。接口模型名须使用服务商 `/models` 返回的准确 ID（大小写敏感）。

歌词补丁适配网易云音乐 3.1.41 x64 Build 205529 与 3.1.42 x64 Build 205594，版本变化时启动器会拒绝注入。官方程序文件不需要修改。

## 独立转换脚本配置

`convert.ps1` 会优先读取同目录的 `converter.settings.json`。可将 `converter.settings.example.json` 复制为 `converter.settings.json` 并按本机路径修改：`InputDirectory` 用于无参数启动时扫描 `.ncm`，`OutputDirectory` 指定统一输出目录，`FfmpegPath` 指定 FFmpeg。未配置输入目录时会打开选择窗口；“选择文件”支持多选和 `Ctrl+A`，“全选文件夹”会递归选中该文件夹及子文件夹内的全部 `.ncm`。未配置 FFmpeg 时会查找脚本同目录、`ffmpeg/bin` 子目录和 PATH。也可继续使用脚本旁的 `output-folder.txt` 保存旧版输出目录设置。

曲风与情绪来自网易云歌曲百科；百科可能缺漏或后续变更，本工具只展示已取得的标签，不把它们当作置信度概率。

## 音乐转换便携使用
音乐转换页提供“选择音乐目录”，不再固定扫描 D 盘。目录配置存放在程序旁的 `input-folder.txt` 和 `output-folder.txt`；程序目录内的路径保存为相对路径，外部目录保存为绝对路径，换电脑后可以重新选择。旧机器的输入目录不存在时，不扫描其他固定盘符，而提示选择目录。转换脚本配置中的相对路径以脚本目录为基准，包括 `InputDirectory`、`OutputDirectory` 和 `FfmpegPath`。

`dist/音乐转换便携包` 包含程序、转换脚本和 FFmpeg；复制整个文件夹到 Windows 10/11 x64 使用，音乐转换不需要 Python。其他功能的运行环境需另行配置。打包不得包含登录会话、Cookie、密钥或本机路径设置。


## 本机播放统计（1.18.0）

“听歌画像 → 本机播放统计”提供每首歌的累计播放次数和连续重播记录。中途切歌、手动重播都计入播放次数，不另列完整播放次数。打开工具箱时采集一次，工具箱运行期间每 3 小时采集；关闭窗口到托盘仍会采集，真正退出后停止。可点击“立即采集”，选择已归档的账号查看记录。

采集由 `local_playback.mjs` 使用随包 Node.js 24 和内置 SQLite 执行，无网络请求。复制客户端 `Library/webdb.dat` 及附属文件，在复制前后核对源文件状态，检查快照 SQLite 文件头并执行 `quick_check`；只在临时副本上允许恢复日志，不写入网易云数据目录。无法获得有效快照时明确报错，下次定时重试。不同数据源部分成功或有无效记录时显示“部分失败”，任务消息保留详情。

记录长期保存在 `%LOCALAPPDATA%\NeteaseToolbox\LocalPlayback\<uid>\plays.sqlite3`，未知账号归入 `unknown`。相同事件重复采集不会增加次数；客户端清理旧记录不影响已保存数据。现有账号最近播放同步仍独立保留；手机网易云重播通过“手机同步”单独接收，并按 2.2.0 的口径并入本页统计。

连续重播按插入顺序、相邻记录 ID 和时间间隔推断。短播放也可接入连续段，切到其他歌曲、记录缺口、记录 ID 重置、时间倒退或超过歌曲时长的 1.5 倍加 25 秒都会分段。没有歌曲时长时使用 240 秒默认值并注明；每段可查看记录 ID、时间、实际已听秒数、来源及间隔。显示次数包含首遍，无法区分自动循环和手动重播，也无法恢复采集前已被客户端清理的历史；未落库的当前播放暂不计入。

验证：`node --disable-warning=ExperimentalWarning toolbox/test_local_playback.mjs` 覆盖 WAL 快照、重复采集、账号隔离、短重播、时间倒退、历史清理、ID 重置、记录更新、部分失败及手机网易云重播合并。`LocalPlaybackValidation.cs` 使用隔离窗体验证真实数据展示、逐条证据、任务反馈和退出停止。

## 音频转麦克风（1.19.0 起，1.20.0 加入真实麦克风混音）

左侧“音频转麦克风”页把网易云正在播放的声音实时送进虚拟声卡，QQ、Discord、游戏语音把该虚拟声卡的录音端当作麦克风，就能听到网易云音乐。工具箱不改动网易云客户端，也不自带声卡驱动。

链路：网易云音乐 → WASAPI（仅网易云进程捕获，或系统声音回环）→ NAudio 音量控制 → 可选与真实麦克风相加 → 限幅保护 → `CABLE Input` → `CABLE Output` → 语音软件麦克风。不保存音频文件，只做实时转发。

页面内按顺序列出了完整使用方法（准备虚拟声卡、装完 VB-CABLE 后改回默认播放 / 录音设备、本页选播放端、语音软件选录音端、混入真实麦克风、开始转发），以及戴耳机、禁止混入同一虚拟声卡录音端等注意事项，可直接照着做（1.20.2）。

- “仅网易云（含子进程）”使用 Process Loopback 只捕获网易云及其子进程，需要 Windows Build 20348 或更高版本；版本不足或激活失败时，状态栏会写明原因，可手动切换到“系统声音（所有应用）”。
- “系统声音”捕获当前默认播放设备上的全部声音。此时不能把输出选成同一个默认播放设备，否则会形成循环回送，工具箱会拒绝启动并提示改回扬声器或耳机。
- 输出设备默认不自动选中扬声器，只匹配名称含 `CABLE Input` 的虚拟声卡播放端；没有虚拟声卡时页面给出官网下载入口和安装步骤，安装并重启电脑后点“刷新设备 / 进程”。没有 VB-CABLE 时也可以用 Steam 自带的“Steam Streaming Microphone”设备对：本页选它的播放端，语音软件里选它的录音端。
- 音乐音量与麦克风音量各自独立，`转发电平`和`麦克风电平`分别显示音量控制后的峰值，`混音输出`显示相加后的最终电平；一旦相加超过满刻度，输出限幅并提示“已限幅”，不会破音。
- 勾选“混入真实麦克风”后才启用麦克风设备、音量和电平；默认麦克风取 Windows 的语音默认录音设备，可自行改选。安装 VB-CABLE 会把 Windows 默认录音设备改成 `CABLE Output`，此时自动选择会跳过虚拟声卡、优先挑真实麦克风，避免把虚拟线自己的录音端当成混音源（1.20.1）。
- 麦克风与输出若属于同一个虚拟声卡，会把转发出去的歌再收回来形成啸叫，工具箱在启动前就拒绝并说明原因（VB-CABLE 的 `CABLE Input`/`CABLE Output`、Steam 的播放端/录音端都会被识别）；真实扬声器与同一适配器上的真实麦克风不受影响。
- 请戴耳机使用混音：外放时麦克风会把歌再收一遍，产生回声或啸叫。开始、运行、停止、失败都会写入底部任务状态栏和“任务消息”。网易云退出、麦克风或输出设备断开、默认播放设备被切换时，转发停止并释放 WASAPI 与音频设备，不会让工具箱崩溃。

验证：`validate-audio.ps1` 覆盖进程激活、连续启停、启动失败后重启、进程退出上报失败、设备释放、系统回环自环拒绝、静音实机转发、麦克风混音启停、坏麦克风设备号安全失败、回环组合拒绝，并断言静音音乐下输出仍带麦克风信号；`validate-audio-layout.ps1` 在隔离窗口中检查页面控件、混音开关联动、文字不截断、两种主题的按钮对比度、滚动范围和任务反馈，整页截图输出到 `dist/audio-page-layout`。该页面校验必须从工作区之外的目录运行，因为工作区中的可执行文件在 Windows 上只能读到部分进程。端到端语音软件收声需在使用者的实际设备上确认。

## 完整便携使用（1.17.0 起）

通过 toolbox/build-portable.ps1 的允许列表打包，排除登录凭证、密钥、本机路径设置、个人歌曲、缓存和报告。包内提供 Python 3.12.10、Node.js 24.19.0、PyCryptodome、qrcode、Frida、psutil、FFmpeg 和 WebView2 配套 DLL，无需安装 Python/Node.js 或修改 PATH。缺少 WebView2 时，通过“配置登录运行环境”或随包的“配置运行环境.cmd”联网安装微软签名的引导程序。程序要求 Windows 10/11 x64 和 .NET Framework 4.8。

画像刷新使用 portable_report.py 生成不依赖外部资源的 HTML 图表报告，沿用既有统计口径，无需 Codex Data 插件或 npm。默认报告位于当前账号的本机 Reports 目录；旧的自定义报告目录配置仍有效。新电脑需重新登录并配置 AI 接口，播放历史和缓存不会随程序自动迁移。

原 Vite 版 `music-profile/report-app` 项目已停用并移出仓库。报告的 `.data-app-offline/exports` 输出目录名是为兼容旧配置保留的。

曲风扫描读取当前音乐目录；音乐记忆同时检索输入与输出目录的歌词，冲突内容不作为证据。三行歌词通过“网易云安装目录”选择客户端，启动器接受 --app-dir 参数；保留原有 DLL SHA-256 校验，适配 3.1.41 x64 Build 205529 与 3.1.42 x64 Build 205594。未包含网易云客户端。运行环境检查、安装和歌词启动的错误会在任务消息中显示。源码保留本地供用户验证，运行时、安装程序及便携包不提交到 GitHub。
