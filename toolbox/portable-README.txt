网易云工具箱便携包（Windows 10/11 x64，.NET Framework 4.8）

首次使用：
1. 将压缩包完整解压到可以写入的目录，保留所有子目录。
2. 打开“网易云工具箱.exe”，在音乐转换页“选择音乐目录”。
3. 如需在线功能，点击左侧“登录网易云”，在官方网页中完成手机扫码与验证。
   如果缺少 WebView2，点击设置与维护中的“配置登录运行环境”，或者双击“配置运行环境.cmd”。
   该操作只在缺少 WebView2 时联网安装微软运行环境。内置 Python 和 Node.js 不会注册到系统或改动 PATH。
4. 默认转换输出在歌曲旁的 unlock 文件夹，可以在设置中改为其他文件夹。
5. 去重请使用“设置与维护 → 曲库安全去重”：先只读扫描并预览，确认后才把选中文件移入音乐目录下的隐藏 .NeteaseToolboxTrash 回收站。
   在“工具箱回收站”中可恢复或手动永久清理；隔离文件在清空前仍占用磁盘空间，不会自动清空。
   转换前会提示跳过已有的低音质重复项，但不会自动删除任何 NCM 或转换输出。

按需配置：
- AI：在“AI 画像接口与提示词”填写接口地址、模型名和 API Key；也可以关闭 AI，仅使用本机统计。
- 三行歌词：在设置中“网易云安装目录”选择包含 cloudmusic.exe 的目录。
  补丁支持网易云 3.1.41 x64 Build 205529 与 3.1.42 x64 Build 205594；哈希不符会拒绝注入，不会绕过版本校验。
  包内包含歌词补丁和 Frida/psutil，未包含网易云客户端。普通转换和画像不要求安装网易云客户端。
- 多人一起听：在左侧“多人一起听”页点“启动并连接”，把电脑接进手机端创建的官方多人房间并跟随播放。
  要求网易云 3.1.41 x64 Build 205529 或 3.1.42 x64 Build 205594，且需完全退出客户端后由工具箱带本机调试通道重新启动；
  只支持恢复房间、跟随换歌与进度、暂停和退出，不支持建房、推歌、共同队列与聊天。
  关闭工具箱不影响已加入的房间；不需要时在本页点“退出并停用”。状态每 5 秒刷新，日志见页面“日志文件夹”。
- 标签歌单：先在“曲风分析”页分析红心歌曲，再点“筛选生成歌单”，可多选情绪/曲风并创建私密或公开歌单；左键勾选，右键给标签标 × 可硬性排除包含该标签的歌曲（类似黑名单）；默认至少命中勾选标签数的一半（单数向上取整），图表会显示各档匹配数量，未分析的歌曲不会加入。
- 音乐记忆：需要本机播放记录，可按日期、时段、歌曲信息或本地歌词检索，结果显示播放时间。
- 本机播放统计：在“听歌画像 → 本机播放统计”查看累计次数和连续重播。打开时采集一次，运行期间每 3 小时采集；退出后停止。
  各账号分别长期保存，中途切歌和手动重播也计入。只覆盖本机客户端已写入且被采集到的记录，无法补回已被客户端清理的历史。
- 手机网易云重播：在本页点“手机同步”，把电脑显示的 6 位配对码输入手机 Music Plus 的“电脑同步”。
  手机和电脑需在同一网络并登录同一网易云账号；首次会补传手机已有的网易云重播，之后自动增量同步。
  成功后 1 小时内不再上传，失败 10 分钟后重试。手机只记录网易云音乐的重播，其他媒体不会进入统计；
  电脑按“重播次数 + 1”推算首遍后并入连续重播和累计次数。首次监听时 Windows 可能询问防火墙权限，请允许专用网络访问。
- 音频转麦克风：把网易云声音送进 QQ、Discord 或游戏语音。需要自备虚拟声卡，例如 VB-CABLE（包内不含驱动）。
  装好后在“音频转麦克风”页选择 CABLE Input，在语音软件的麦克风设置中选择 CABLE Output；页面有官网下载入口和安装步骤。
  没有 VB-CABLE 时也可以用 Steam 自带的“Steam Streaming Microphone”设备对：本页选播放端，语音软件里选录音端。
  只做实时转发，不保存音频。“仅网易云”模式需要 Windows Build 20348 或更高版本，失败时可手动改用“系统声音”。
  勾选“混入真实麦克风”可把自己的说话声和音乐一起送出（各自音量、带限幅）。请戴耳机使用，外放会产生回声或啸叫；
  麦克风与输出属于同一虚拟声卡时会被拒绝，避免啸叫。
  注意：安装 VB-CABLE 会把 Windows 默认播放和默认录音设备都改成 CABLE 两端，装完请到“声音设置”里
  把默认播放改回扬声器 / 耳机、默认录音改回真实麦克风，否则其他软件的声音会听不到、也都会被送进虚拟线。

已包含 FFmpeg、Python 3.12.10、Node.js 24.19.0、PyCryptodome 3.23.0、qrcode 8.2、Frida 17.2.17、psutil 6.1.1、NAudio 2.2.1，
以及 WebView2 配套 DLL 和微软签名的在线安装引导程序。画像报告在本机生成，不需要安装 Codex、npm 或插件。
音乐转换可以离线运行。在线登录、歌词、多人一起听、网易云标签、账号档案和 AI 请求需要对应服务可连接。

路径和数据：
程序目录内选择的输入/输出路径以相对路径保存；外部目录使用绝对路径，换电脑后可重新选择。
歌曲、已有输出、播放记录不会自动从旧电脑迁移。新电脑需要重新登录并配置 AI 密钥。
登录会话、AI 密钥和账号缓存保存在该电脑当前 Windows 用户的 LOCALAPPDATA/NeteaseToolbox 下。
登录与密钥使用 DPAPI 保护，不能把旧电脑的加密会话直接复制给另一台电脑。
报告按账号隔离保存在用户目录；报告可通过浏览器保存并分享，但包含个人听歌偏好。
包内没有个人账号、Cookie、API Key、歌曲、播放记录或生成报告。
启动后会注册本机登录启动项用于播放记录同步；关闭窗口会隐藏到托盘，托盘菜单可以关闭自动同步。

维护：
可在设置中点击“检查运行环境”，查看缺少的文件和待配置项目。
manifest.json 记录组件 SHA-256，便于检查搬运后的文件是否完整。
