# 网易云++ / 网易云工具箱

面向 Windows 10/11 x64、.NET Framework 4.8 的本地音乐工具，当前公开源码同步至 **2.3.1.0**。

- NCM 转换、标签、封面与歌词提取，以及带预览和回收站的安全去重。
- 网易云扫码登录、曲风与情绪标签、标签歌单预览与规则预设。
- 听歌画像、本地 HTML 图表报告、播放记录同步、本机累计播放与连续重播统计、手机网易云重播同步。
- 仅依据播放记录和本地歌词的音乐记忆检索，可选 AI 画像与候选排序。
- 每日签到、主题与背景设置（含背景蒙版）、音频转麦克风及可选麦克风混音。
- 三行桌面歌词和官方多人一起听实验补丁，适配网易云音乐 3.1.41.205529 与 3.1.42.205594 x64，并执行文件哈希及结构校验。

## 使用与构建

运行环境及操作说明见 [工具箱说明](toolbox/README.md) 和 [便携使用说明](toolbox/portable-README.txt)，多人补丁说明见 [listen-together](listen-together/README.md)。客户端更新后需要重新适配，不能复用未知版本的函数偏移。

在 Windows PowerShell 中执行 `toolbox/build.ps1` 构建。脚本会按需从官方 NuGet 下载并校验 WebView2 与 NAudio SDK。准备所需运行时和 FFmpeg 后，可执行 `toolbox/build-portable.ps1` 按允许列表生成便携包。源码仓库不包含这些二进制依赖或网易云客户端。本次同步更新源码并发布 2.3.1 完整便携包，见 Releases。

## 隐私与文件操作

公开快照不包含个人账号、Cookie、API Key、会话、歌单或房间标识、听歌记录、统计结果、个人报告、截图、本机路径配置和私有 Git 历史。测试使用合成样本；第三方源码的许可证与署名保留。

使用时登录凭证和 AI 密钥由当前 Windows 用户的 DPAPI 保护，缓存及记录按账号保存在本机用户目录。新电脑需要重新登录并自行配置 AI。AI 配置只从工具箱自身设置读取；启用 AI 时，相关音乐信息会发送到用户配置的模型服务。

安全去重会先只读扫描并预览，确认后才把选中的重复文件移入音乐目录下的 `.NeteaseToolboxTrash` 隔离区，可在工具箱回收站恢复；不会自动删除源 NCM 或转换输出。手机重播同步只在同一局域网、同一网易云账号绑定后传输重播统计，配对码或账号不一致会拒绝。首次运行会注册当前用户的登录启动项用于播放记录同步，可从托盘菜单关闭。任务开始、完成、失败或部分失败均在界面及任务消息中显示。

## 源码目录

- `toolbox/`：WinForms 界面、登录、分析、播放统计、手机同步、签到、音频转发及便携构建脚本。
- `convert.ps1`：转换、标签、封面、歌词和只读重复扫描。
- `desktop-lyrics/`：三行歌词源码、兼容性配置和回归测试。
- `listen-together/`：多人一起听源码、说明与测试；运行组件同时保存在 `toolbox/multi-listen/`。
- `music-profile/`：画像统计及报告数据生成。

第三方组件的许可说明随源码保留，FFmpeg 许可与源码信息见 [FFmpeg 官方说明](https://ffmpeg.org/legal.html)。
